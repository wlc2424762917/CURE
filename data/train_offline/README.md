# Quickstart training data

`advanced_tree_data.json` is the legacy offline training dataset used by the
quickstart. 

The JSON file is tracked with Git LFS. After cloning, install Git LFS and run
`git lfs install` and
`git lfs pull --include="data/train_offline/advanced_tree_data.json"`
from the repository root. Model weights are
obtained separately using the model IDs or local paths in the quickstart.
